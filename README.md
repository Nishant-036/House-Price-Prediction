# House Price Prediction using Python

## Project Overview
This project performs exploratory data analysis and machine learning on housing data to predict house prices.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Features
- Data cleaning
- Missing value analysis
- Histograms and boxplots
- Correlation matrix
- Feature engineering
- Linear Regression model

## Model Performance
- MAE: 32767.66
- R² Score: 0.6505
